# FastAPI Quote Generator API

A simple REST API built using FastAPI and Python that generates motivational quotes in JSON format.

## Technologies Used

* Python
* FastAPI
* Uvicorn

## Features

* REST API endpoints
* JSON responses
* Random quote generator
* Swagger API documentation

## Run Project

```bash
python -m uvicorn main:app --reload
```

## API Endpoints

* `/`
* `/quote`
